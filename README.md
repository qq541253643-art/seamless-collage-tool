# 无缝拼图工具

绿色、免安装的 Windows 拼图工具。可以将多张图片和 1 段视频放入模板或自定义格子，导出 JPG 或带原声的 MP4。所有编辑与导出均在本机浏览器完成。

## 视频拼图

- 支持多张图片 + 1 段视频；视频可像图片一样移动、缩放、旋转和裁切。
- 画布内可静音预览和拖动时间轴；导出 MP4 时保留原视频声音。
- MP4 使用 H.264 视频和 AAC 音频；导出前会检测当前电脑的编码能力。
- 导出按视频时长实时进行，期间会锁定编辑并显示进度，可随时取消。
- 建议使用最新版 Edge 或 Chrome，并保持显卡驱动为新版本。

## 一条命令安装

在 Windows PowerShell 中粘贴并回车：

```powershell
irm https://raw.githubusercontent.com/qq541253643-art/seamless-collage-tool/main/install.ps1 | iex
```

程序会安装到当前用户的“文档\无缝拼图工具”，并在桌面创建“无缝拼图工具”快捷方式。以后从桌面快捷方式打开即可。

## 更新

从桌面快捷方式打开时，程序会读取仓库的 `manifest.json`，只下载内容发生变化的文件。网络不可用时会继续打开已经安装的版本，检查结果保存在安装目录的 `update-status.txt`。

## 手动使用

下载仓库后双击“打开拼图工具.cmd”，或直接打开 `app.html`。

支持 Windows 10/11，建议使用新版 Edge 或 Chrome。
